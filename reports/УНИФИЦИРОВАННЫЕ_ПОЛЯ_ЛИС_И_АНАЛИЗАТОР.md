# Унифицированные поля входящих данных

Два словаря: **ЛИС (Damumed)** и **анализатор**.  
Одно каноническое поле = все синонимы из отчётов и логов. Повторов по видам отчётов нет.

Связка потоков: `№ направления` (ЛИС) = `штрих-код пробы` (анализатор). Пациентских полей в потоке анализатора нет.

---

## ЛИС (Damumed) — единый список

Все поля, которые система умеет достать из любого отчёта Damumed.  
Если поле есть не во всех журналах — указано в колонке «где бывает».

### Идентификаторы

| Каноническое поле | Как называется в отчётах | Где бывает |

| Номер заказа | Номер заказа | брак |

| RPNID пациента | RPNID пациента | выполненные |
| Код услуги | Код услуги | положительные, ГОБМП |

| № истории болезни | № истории болезни, амбулаторной карты | направления, выполненные |
| № амбулаторной карты (дубль) | отдельная колонка в CSV | направления — **в систему не берётся** |

## Анализатор — единый список

Всё, что приходит из Applogs (текст + HL7 + JSON) и `errors.xml`.  
Одна каноническая сущность = **проба / прогон**.

### Идентификаторы пробы и заказа ЛИС

| Каноническое поле | Откуда | В БД? |
|---|---|---|
| Штрих-код / код пробы | `SAMPLE! …`, HL7 `OBR-3`, XML `Sample@Code` | да `barcode` |
| ID исследования ЛИС | JSON `OrderResearchID` | да `order_research_id` |
| ID заказа ЛИС | JSON `OrderResearch.OrderID` | да `order_id` |
| ID услуги ЛИС | JSON `ServiceMo.ServiceID` | да `service_id` |
| ID услуги МО | JSON `ServiceMoID` | нет |
| ID записи результата | JSON `ID` / `StrID` | нет |
| UUID исследования | JSON `Uid` | нет |
| Составной SourceID | JSON `SourceID` | нет |
| Есть заказ в ЛИС | `Sample request count`, `THERE IS NO SR` | да `has_lis_order` |
| Число направлений на пробу | `Sample request count: N` | да `sample_request_count` |

### Прибор / рабочее место

|---|---|---|

| ID анализатора в ЛИС | JSON `AnalyzerId` | да `lis_analyzer_id` |

## Связка двух списков

| Смысл | ЛИС | Анализатор |
|---|---|---|
| Ключ склейки | № направления | штрих-код пробы |
| Услуга | наименование услуги | `service_name` / `service_id` |
| Пациент, ИИН, заказчик, диагноз, врач | только ЛИС | нет |
| Фактический прогон и реагенты | нет | только анализатор |
| Результат анализа | редко, текст в журнале выполненных | 4 числа в БД, остальные в файле |
